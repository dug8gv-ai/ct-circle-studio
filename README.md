# CT Circle Studio

My Favorite CT Friends Banner Maker — upload your favourite friends' profile pictures, pick a banner ratio, choose a layout, and download a high-quality banner with **My Favorite CT Friends** in the centre.

- Mobile-first banner studio
- Ratios: 16:9 (default), 3:1 X banner, 1:1, 4:5, 9:16, 4:3
- Layouts: Ring, Rows, Frame, Grid, Scatter, Arc, Columns
- Unlimited friends — profile pictures auto-shrink as more are added
- @handle labels under each friend, best-friend star highlight, host PFP
- 12+ backgrounds + custom gradient / custom background image
- Editable centre text, fonts, colours and text effects
- X profile / post preview, ready-to-copy caption
- High-quality PNG / JPG download — photos never leave the device

Powered by [@ShoaibCT_](https://x.com/ShoaibCT_)

## Run

Open `index.html` in a browser, or deploy the folder as a static site on Vercel.
